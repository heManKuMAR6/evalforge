# EvalForge Examples

Each folder shows how to use EvalForge with a specific agent framework.

## Run an example

cd examples/langchain
python basic_eval.py

## Frameworks covered

| Framework | Example |
|-----------|---------|
| LangChain | examples/langchain/basic_eval.py |
| CrewAI | examples/crewai/basic_eval.py |
| AutoGen | examples/autogen/basic_eval.py |
| OpenAI Agents SDK | examples/openai-agents/basic_eval.py |
